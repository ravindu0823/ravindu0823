## 🚀 Featured work

> 🔒 Most of this is client work in private repositories, so there is no code to link. The write-ups stick to architecture.

### ⚡ Real-time content platform
*Lead engineer, ~90% of 480+ commits*

Feeds, 24-hour stories, chat and live streaming on .NET 10 and Aspire, built for high-frequency fan-out. A CQRS read/write split with read-replica fallback, Redis with compiled queries, and three async lanes: Hangfire, MassTransit on RabbitMQ, and in-process channels.

`ASP.NET Core` `Aspire` `EF Core` `Redis` `RabbitMQ` `Azure DevOps`

### 🕸️ Agent network & commission engine
*Core engineer*

A multi-tenant platform with a 10-level agent hierarchy on PostgreSQL `ltree`, an automated commission engine, and a central identity hub that issues JWTs and permissions to peer services. Memory-heavy imports run as a scale-to-zero Container Apps job fed by Service Bus. Auth covers WebAuthn passkeys, TOTP, refresh-token rotation and HMAC signing.

`.NET 9` `PostgreSQL` `Service Bus` `Container Apps` `Bicep` `APIM`

### 💸 Multi-currency wallet & double-entry ledger
*Contributing engineer*

Every deposit, transfer, FX conversion and withdrawal lands in an immutable double-entry ledger. Exactly-once idempotency with encrypted, time-bound keys, HMAC-SHA256 signed partner APIs, and Serializable transactions with retries and optimistic concurrency to prevent double-spend.

`Clean Architecture` `EF Core` `PostgreSQL` `Redis` `Aspire`

### 🎯 Real-time event data & settlement platform
*Lead backend engineer*

Ingests live event data from a third-party feed and moves money through an external wallet provider. Idempotent transfers (stable reference IDs, HMAC-signed callbacks, refund and rollback paths), an automated settlement engine, and a multi-tenant model behind a JWT-secured admin console.

`ASP.NET Core 9` `PostgreSQL` `Next.js` `GitHub Actions` `Dokploy`

### 🧱 .NET 10 API platform template
*Sole author*

A `dotnet new` template that scaffolds a production-ready Web API in one command and is used across the team: Clean Architecture, refresh-token rotation with family revocation, EF Core audit and slow-query interceptors, Redis, Hangfire, SignalR, Serilog and OpenTelemetry.

`.NET 10` `EF Core 10` `Aspire` `OpenTelemetry`

### 🌦️ ResilienceOS
*Personal project*

Six event-driven .NET 10 services on Aspire. They ingest weather feeds, run ML.NET risk predictions and push real-time alerts over Azure SignalR. CQRS vertical slices, Service Bus with dead-lettering, PostGIS and TimescaleDB storage, and architecture tests with NetArchTest. Canary deploys run on Kubernetes with Helm and Flagger.

`.NET 10` `ML.NET` `TimescaleDB` `Kubernetes` `TestContainers`
